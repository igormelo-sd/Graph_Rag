# Documento demonstrativo: Biblioteca Horizonte

Este documento é fictício e serve apenas para testar o RAG.

A Biblioteca Horizonte funciona de segunda a sexta-feira, das 8h às 18h.
O cadastro é gratuito e exige apresentação de documento de identidade.
Cada pessoa cadastrada pode retirar até três livros por vez.
O prazo de empréstimo é de 14 dias, com uma renovação caso não haja reserva.

O espaço possui uma sala de leitura, computadores para pesquisa e acesso Wi-Fi.
As oficinas de leitura acontecem às quartas-feiras, às 15h.
